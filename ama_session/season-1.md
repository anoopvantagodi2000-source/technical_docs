# Today's AMA Session

### 1. What is a List in Python?
- Lists are ordered collections of homogeneous or heterogeneous data.

### 2. What is the difference between git pull and git fetch?
- `git fetch` - Downloads new history/commits from the remote repo.
- `git pull` - Downloads new history and integrates it into your current branch.

### 3. What is a Process?
- A process is a running instance of a program.

### 4. What is an Operating System?
- An operating system is software which helps us manage hardware.

### 5. What is the difference between git log and git status?
- `git status` helps us track changed and unchanged files.
- `git log` gives us the history of commits.

### 6. What is the List extend method?
- Appends all the individual elements of an iterable (such as a list, tuple, set, or string) to the end of the current list and returns `None`.

### 7. How can we get the first 10 lines of a file?
- By using `head -n 10`.

### 8. What is the difference between a kernel and a shell?
- **Kernel:** Allocates hardware resources to running programs.
- **Shell:** Translates human inputs into system calls.

### 9. When to use a for loop and a while loop?
- A `for` loop is used when the number of iterations is known.
- A `while` loop is used mostly when the number of iterations is not predefined.

### 10. What is the command to check the architecture of a system?
- `uname -m`

### 11. What is the use of a Branch?
- Used when we work on new features without affecting the main code.

### 12. When we use cat, what will happen if we use > and >>?
- `>` is used to replace the entire text in a file.
- `>>` is used to append to a new line in a file.

### 13. What is the difference between sort and sorted?
- `sorted()` - Creates a brand new list in sorted order.
- `sort()` - Goes for in-place sorting and returns `None`.

### 14. How can we check the commits?
- `git log`

### 15. What is the use of venv?
- The `venv` module in Python is used to create isolated virtual environments. It acts as a lightweight sandbox for each of your projects, ensuring that they have their own independent set of packages and dependencies.

### 16. What do variables do in Python?
- A variable is a named label that points to a specific value stored in your computer's memory.

### 17. What is the difference between an Absolute path and a Relative path?
- The core difference between an absolute path and a relative path is their starting point: an absolute path specifies the complete location from the root directory, while a relative path specifies the location relative to your current working directory.
