# Command Line Interface

**SHELL** - It's command line interpreter that executes text commands

**Terminal** - application that help us write commands.


## Basics Commands

**man** - man command gives us information of other commands.
eg - man ls displays information about ls

**pwd** - It displays information about which directory we are working on.

**ls** - Displays what are the files/directories present in current working directory,by default it does not display
        hidden files.

**mkdir** - Creates the folder at specified location.

**rm** - Deletes file or directories permanently from file system

**touch** - creates a file in file system.

**find** - used to search files or directories in file system.

**grep** - used to search for specific text patterns inside file or command output.

**cat** - used to display the file content of given file.

**cd** - used to change directories.


##  System, Process, & Resource Monitoring

__top__ or __htop__ - displays active systems process,live cpu usage, and memory consumption.

__ps aux__ - displays all active processes on machine.

__kill -9 <PID>__ - instantly terminates process.


## Networking and Connectivity 
__curl -i <URL>__ - send web request to URL.

__ping <host>__- Check if remote server is online
