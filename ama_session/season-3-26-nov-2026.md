
1. **What is the difference between `span` and `div`?**  
   `div` is a block-level element used to group larger sections of content, whereas `span` is an inline element used to style or group small portions of text.

2. **What are semantic elements?**  
   Semantic elements are HTML elements that clearly describe their meaning and purpose, such as `header`, `footer`, `article`, and `section`.

3. **What is the use of the `href` attribute?**  
   The `href` attribute specifies the URL or destination of a link in an HTML anchor (`a`) element.

4. **How can you check if there is a number in a string?**  
   In Python, we can use `any(char.isdigit() for char in string)` to check whether a string contains at least one digit.

5. **How can we give input to a dictionary?**  
   In Python, we can add or update dictionary values using `dictionary[key] = value`.

6. **What is the difference between `vh` and `vw`?**  
   `vh` represents 1% of the viewport height, whereas `vw` represents 1% of the viewport width.

7. **What is the use of the `name` attribute in radio inputs?**  
   The `name` attribute groups radio buttons so that only one option within the same group can be selected at a time.

8. **What is the difference between Flexbox and Grid?**  
   Flexbox is a one-dimensional layout system used to arrange elements in a row or column, whereas Grid is a two-dimensional layout system that handles rows and columns together.

9. **What is the difference between ordered and unordered lists?**  
   An ordered list (`ol`) displays items with numbers or letters, whereas an unordered list (`ul`) displays items with bullet points.

10. **Explain the CSS box model.**  
    The CSS box model describes how an element's content, padding, border, and margin determine its total size and spacing.

11. **What are the values of `flex-direction`?**  
    The four values of `flex-direction` are `row`, `row-reverse`, `column`, and `column-reverse`.

12. **How do we create a dropdown in HTML?**  
    We use the `select` element with nested `option` elements to create a dropdown menu.

13. **What is a lambda function?**  
    A lambda function is a small anonymous function in Python that contains a single expression and is defined using the `lambda` keyword.

14. **What is the use of the `git pull` command?**  
    The `git pull` command fetches the latest changes from a remote repository and integrates them into the current local branch.

15. **How can we append an element to a set?**  
    In Python, we use the `add()` method to insert a single element into a set.
